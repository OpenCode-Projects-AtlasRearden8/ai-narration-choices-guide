## Decision bands

- [ ] **21–25** — Strong yes. Offer / confirm booking.
- [ ] **16–20** — Caution. Try one more sample before committing.
- [ ] **11–15** — Cross off this candidate.
- [ ] **Under 11** — Hard no.

## Red flags log (any one is a no)

- [ ] Mispronunciation with no fix (or with an unre-graded retry)
- [ ] Mouth clicks / sticky pops entering "fatigue" territory
- [ ] Character voices blur or switch sides mid-chapter
- [ ] AI voice: audible air-swallow artifacts, mushed plosives, "list voice"
- [ ] mono-temperature long dramatic passage — reworded: a long dramatic passage held
      at one flat emotional temperature
- [ ] Chapter-to-chapter drift (energy, loudness, character pitch)
